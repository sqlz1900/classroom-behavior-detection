# 学生课堂行为检测系统 — 开发计划

> 基于_YOLO11_(Ultralytics)_+_摄像头实时检测_举手/睡觉/玩手机/趴桌/听讲，支持图片、视频、摄像头三种检测方式，可自定义训练。

---

## 一、系统架构

```
浏览器 (Vue3 + TS + Element-Plus)
   │  HTTP / MJPEG 视频流
   ▼
SpringBoot :8080  ──── MySQL :3306（检测记录、班级/课程、预警事件）
   │  HTTP 转发（RestClient）
   ▼
Flask AI 服务 :5002 ─── YOLO11 模型（GPU RTX 4060）
   │  OpenCV
   ▼
图片文件 / 视频文件 / 摄像头(cv2.VideoCapture)
```

**职责划分**
| 模块 | 职责 |
|---|---|
| Flask AI 服务 | 模型推理、图片/视频检测、MJPEG 实时流、预警回调、模型重载（支持训练后热替换） |
| SpringBoot | 业务 API：检测记录/统计/班级课程管理、预警事件、阈值配置、转发 AI 请求 |
| Vue3 前端 | 图片/视频/摄像头三个检测页 + 记录统计看板 + 预警中心 + 系统设置 + 深色/色弱模式 |
| 训练模块 | 数据集配置、训练/验证/导出脚本 |

## 二、行为类别（5 类）

| 类别 | 中文 | 预警级别 |
|---|---|---|
| raise_hand | 举手 | 正常 |
| listen | 听讲 | 正常 |
| sleep | 睡觉 | ⚠ 预警 |
| phone | 玩手机 | ⚠ 预警 |
| bow_head | 趴桌/低头 | ⚠ 预警 |

> 玩手机与趴桌低头共用 phone 类的底层姿态特征，在数据标注阶段合并策略可调。

## 三、里程碑

### M1 基础设施（先做）
1. **工具链免安装**（tools/ 目录，zip 解压即用，无需管理员）：
   - JDK 17 (Temurin)、Maven 3.9、FFmpeg（git-bash 可用）
2. **Python 环境**：conda 新建 `yolo11` 环境（Python 3.10）+ cu121 torch + ultralytics + flask + opencv + pymysql
3. **数据库**：建库 `classroom_behavior` + 表结构（DDL 脚本 database/schema.sql）

### M2 Flask AI 服务（ai-service/）
- `detector.py`：YOLO11 推理封装（模型懒加载、GPU 优先、热重载）
- `app.py` REST API：
  - `POST /api/detect/image` — 图片检测（base64 进 / 标注图+框列表出）
  - `POST /api/detect/video` — 视频检测（抽帧，输出标注视频 mp4）
  - `GET  /api/stream/start|stop|status|mjpeg` — 摄像头实时检测 + MJPEG 流
  - `POST /api/model/reload` — 热重载训练好的新模型
  - `GET  /api/health`
- 预警逻辑：检测到 sleep/phone/bow_head 且持续 ≥ N 帧 → POST 回调 SpringBoot `/api/alerts/ai-callback`
- 视频处理优先用 OpenCV（FFmpeg 作为备份方案及转码工具）

### M3 SpringBoot 后端（backend/）
- Spring Boot 3.3 + MyBatis-Plus + MySQL
- 表：`detection_record`（每次检测一条，含各类别计数、标注图路径）、`alert_event`（预警事件）、`classroom`（班级）、`course`（课程）、`sys_config`（阈值/模型路径配置）
- API：记录分页查询、统计看板（按天/按行为聚合）、预警列表与确认处理、配置读写
- AI 代理接口：前端不直连 Flask，全部经 SpringBoot 转发（统一鉴权与记录落库）
- JDBC 连接复用本机 MySQL80（root，凭据写入 application-local.yml，gitignore）

### M4 Vue3 前端（frontend/）
- Vite + Vue3 + TypeScript + Element-Plus + Pinia + Vue Router
- 页面：实时监控（MJPEG+预警弹窗）、图片检测、视频检测、检测记录、统计看板(ECharts)、预警中心、系统设置
- 主题：深色模式 / 色弱模式 / 布局大小（CSS 变量 + html data 属性，持久化 localStorage）
- 开发期 vite proxy `/api` → 8080

### M5 训练模块（training/）
- `dataset.yaml`（5 类，路径指向 dataset/）、`train.py`（yolo11n/s，传入 --epochs/--batch/--model，默认 100 epoch、batch 16、640px、AMP）、`val.py`、`predict_test.py`
- 数据获取指引（docs/训练数据指引.md）：推荐 ROBOFLOW 搜索 "classroom behavior" / "student sleep phone" 公开数据集导出 YOLO 格式；标注用 LabelImg/Roboflow
- 冷启动方案：先用 yolo11n COCO 预训练权重做「person+手机近似映射」演示模式（能跑通全链路），标注数据到位后重训替换

### M6 端到端验证
- 建库 → 启动 Flask(5002) → 启动 SpringBoot(8080) → 启动前端(5173)
- 用本机摄像头/测试图片实测：检测出框、记录入库、预警触发、前端展示

## 四、端口与约定

| 服务 | 端口 |
|---|---|
| Flask AI | 5002（5000 已被占用） |
| SpringBoot | 8080 |
| Vue 前端 | 5173 |

- 上传/输出目录：`ai-service/static/`（标注图、标注视频，由 SpringBoot/前端经 Flask 静态路由访问）
- 模型文件：`ai-service/models/best.pt`（训练产物复制/热重载至此）

## 五、风险与对策

| 风险 | 对策 |
|---|---|
| 无 5 类标注数据集 | M5 冷启动演示模式先跑通链路；提供数据集获取与训练全流程 |
| JDK/Maven 无管理员安装 | zip 免安装到 tools/，仅设会话变量 |
| GPU 显存 8GB | yolo11n/s + batch 16 + AMP 足够 |
| MJPEG 延迟/带宽 | 640px 宽 JPEG、质量 70、限 ~20fps；前端 img 流直连 Flask（开发期 vite proxy 支持流式） |
| 端口冲突 | Flask 用 5002；启动前检测 |

## 六、不做的事（明确边界）

- 不做多摄像头分布式；单摄像头即可
- 不做用户登录鉴权体系（本地演示系统，如需可后加）
- 不引入 Redis/Kafka 等重中间件
