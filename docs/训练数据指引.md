以下为通用指引（自标注 / 其他来源）：


## 一、推荐：Roboflow 公开数据集（最快）

1. 注册 https://roboflow.com （免费）
2. 搜索关键词（Universe 频道）：
   - `classroom behavior`
   - `student engagement`
   - `sleep detection classroom`
   - `phone detection person`
3. 选数据集 → **Download Dataset → Format: YOLOv11 (或 YOLOv8，格式兼容)**
4. 下载解压后，把图片与 txt 标签分别合并到：
   ```
   training/dataset/images/train/   training/dataset/labels/train/
   training/dataset/images/val/     training/dataset/labels/val/
   ```
5. ⚠ 合并后检查类别顺序必须与 `training/dataset.yaml` 一致：
   `0=raise_hand 1=listen 2=sleep 3=phone 4=bow_head`
   若数据集类别名不同（如 head_down / bow），写一个脚本批量重映射 txt 里的类别 id。

## 二、自标注

- 工具：LabelImg（YOLO 格式）或 Roboflow Annotate（网页标注，可自动标注预打标）
- 教室实拍：每类 ≥ 300 张，尽量覆盖不同光照/角度/人数密度
- 划分 train:val ≈ 8:2

## 三、类别定义（标注口径）

| id | 类别 | 标注口径 |
|----|------|----------|
| 0 | raise_hand | 手臂举起高于桌面/头部 |
| 1 | listen | 正常坐姿面向前方 |
| 2 | sleep | 头枕手臂/后仰闭眼 |
| 3 | phone | 手持手机低头看 |
| 4 | bow_head | 低头（桌面方向，非持机） |

边界情况：玩手机 vs 趴桌低头难以区分时，按「是否可见手机矩形」判定。
